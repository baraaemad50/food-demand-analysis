# قرارات تنظيف البيانات

## النطاق

تستند هذه القرارات إلى نتائج دفتر [02_data_preparation.ipynb](../notebooks/02_data_preparation.ipynb) عند فحص `train.csv` و`meal_info.csv` و`fulfilment_center_info.csv`.

المسار `data/raw/` غير موجود في المشروع؛ الملفات الخام التي قرأها الدفتر موجودة في `data/dataraw/`. قُرئت الملفات دون تعديلها. احتوى `train.csv` على **456,548 صفًا** ومجموع `num_orders` قدره **119,557,485**.

## جدول القرارات

| المشكلة / الفحص | عدد الحالات | القرار | السبب |
|---|---:|---|---|
| مفاتيح `meal_id` غير المتطابقة عند ربط الطلبات ببيانات الوجبات | 0 | الاحتفاظ بالربط اليساري والتحقق من أن عدد الصفوف ومجموع الطلبات لم يتغيرا | كل مفاتيح الوجبات في بيانات الطلبات لها تطابق؛ لم تُفقد صفوف أو طلبات في الربط. |
| مفاتيح `center_id` غير المتطابقة عند ربط النتائج ببيانات مراكز التجهيز | 0 | الاحتفاظ بالربط اليساري والتحقق من ثبات عدد الصفوف ومجموع الطلبات | كل مفاتيح مراكز التجهيز في بيانات الطلبات لها تطابق. |
| قيم مفقودة في ملفات المصدر أو البيانات بعد الدمج | 0 | لا تعبئة ولا حذف | لا توجد قيم مفقودة تتطلب معالجة في البيانات المفحوصة. |
| صفوف مكررة بالكامل في ملفات المصدر أو البيانات المدمجة | 0 | لا حذف للتكرارات | لم يُرصد تكرار كامل للصفوف. |
| مفاتيح مكررة: `train.id` و`meal_info.meal_id` و`fulfilment_center_info.center_id` | 0 في كل مفتاح | لا إزالة لمفاتيح | المفاتيح فريدة في الملفات المفحوصة؛ كما نجح التحقق من علاقة الربط `m:1`. |
| `checkout_price <= 0` أو `base_price <= 0` | 0 لكل شرط | لا تعديل | لم تُرصد أسعار صفرية أو سالبة. |
| `checkout_price > base_price` | 116,101 صفًا (25.43%) | الإبقاء على الصفوف ووضعها للمراجعة؛ لا تصحيح آلي للسعر | التجاوز قد يعكس خصومات أو قواعد تسعير أو اختلافًا في معنى الحقول، ولا يكفي وحده لإثبات وجود خطأ. تُراجع الحالات مع تعريف الأسعار ومصدرها، مع مراعاة مؤشرات الترويج. |
| `checkout_price` خارج حدود IQR المحسوبة لكل وجبة | 30,233 صفًا (6.62%) | الإبقاء على القيم واعتبارها إشارات تستحق الفحص | اختلاف نطاق أسعار الوجبات يجعل حدًا عالميًا مضللًا، وحتى حدود IQR لكل وجبة تحدد قيمًا متطرفة إحصائيًا لا أخطاء مؤكدة. |
| `base_price` خارج حدود IQR المحسوبة لكل وجبة | 38,017 صفًا (8.33%) | الإبقاء على القيم واعتبارها إشارات تستحق الفحص | القيمة المتطرفة قد تكون حقيقية أو مرتبطة بتغير تسعير؛ لا يوجد دليل كافٍ لاستبدالها أو حذفها. |

## نتيجة قرارات التنظيف

لم يُحذف أو يُملأ أو يُعدّل أي سجل أو سعر. تبقى مجموعة البيانات بعد الدمجين **456,548 صفًا** ومجموع الطلبات **119,557,485**. أعداد حالات تجاوز السعر وحدود IQR قد تتداخل، لذلك لا ينبغي جمعها للحصول على إجمالي مشكلات فريد.

قبل أي معالجة لاحقة للأسعار، تحقّق من تعريف `checkout_price` و`base_price` ومن قواعد العروض لدى الشركة. أعد تشغيل الدفتر إذا تغيرت ملفات المصدر؛ الأعداد أعلاه توثق نتيجة الفحص الحالي فقط.
